# Implementation Order

1. Foundation and build baseline.
2. Persistence/security defects.
3. Protocol contracts and compatibility fixtures.
4. Network transport abstraction.
5. Explicit GameContext/state ownership.
6. Domain extraction.
7. Content engine.
8. Platform services.
9. Observability maturation.
10. Scale architecture based on measurements.
11. New future-facing gameplay systems.

This order is normative unless superseded by an ADR.
