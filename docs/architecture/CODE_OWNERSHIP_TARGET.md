# Code Ownership Target

The modernization will converge toward explicit ownership boundaries:

- Platform: build, config, logging, database infrastructure.
- Protocol/Network: transport and WYD compatibility.
- World: entities, spatial state, movement and replication.
- Character: progression, inventory, equipment.
- Combat: skills, effects, damage and PvP rules.
- Social: party, guild, alliance/war.
- Content: quests, events, drops, crafting, shops.
- Economy: trade, currencies, marketplace and audit.

Ownership here is architectural, not a GitHub team assignment yet.
